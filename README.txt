HOTEL MANAGEMENT SYSTEM - JAVA CONSOLE PROJECT
================================================

IDE:
IntelliJ IDEA

LANGUAGE:
Java

TYPE:
Console-based application

PERSISTENCE:
Text files using FileReader, FileWriter, BufferedReader and BufferedWriter.

FEATURES:
1. Customer management
2. Room management
3. Booking management
4. Check-in and check-out
5. Hotel services
6. Payment management
7. Employee management
8. Searching
9. Transaction history
10. Customer account statements
11. Booking statements
12. Revenue report
13. Occupancy report
14. Hotel summary
15. Basic data validation
16. Automatic ID generation
17. File-based persistent storage

HOW TO RUN IN INTELLIJ:
1. Create a new Java project.
2. Create a folder named src if IntelliJ did not create one.
3. Put all .java files in the same source folder.
4. Do NOT add a package statement.
5. Open Main.java.
6. Right-click Main.java and select Run 'Main.main()'.
7. A folder called hotel_data will be created automatically.
8. The program stores records in text files inside hotel_data.

IMPORTANT:
All Java files belong to the same default package.
The application creates these files automatically:
customers.txt
rooms.txt
bookings.txt
services.txt
payments.txt
employees.txt
transactions.txt

The sample room/service/employee records are created on first run.
